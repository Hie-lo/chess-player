# ♞ chess-player — استودیو تحلیل زندهٔ شطرنج

ابزار **تحلیل لحظه‌ای و تمرین تعاملی** شطرنج با موتور Stockfish: روی تختهٔ
وب‌اپ حرکت می‌کنید و موتور همان لحظه وضعیت را ارزیابی می‌کند — نوار
ارزیابی، **فلش بهترین حرکت بعدی** و **سه خط برتر (MultiPV)**. به‌علاوه:
بازی تمرینی مقابل موتور، حالت «حدس بهترین حرکت» با امتیازدهی، تحلیل کامل
بازی‌های تمام‌شده (دقت/ACPL و برچسب اشتباه‌ها)، مرور قدم‌به‌قدم PGN با
تحلیل زندهٔ هر وضعیت، و خواندن وضعیت از روی تصویر تخته‌ای که خودتان
می‌دهید (با ویرایشگر تأیید).

> ⚖️ **قلمرو استفاده**
>
> این یک ابزار تمرین شخصی است و تخته‌اش **داخل خود برنامه** است؛ به هیچ
> سایت بازی آنلاینی وصل نیست و صفحهٔ بازیِ شخص دیگری را نمی‌خواند. کمک
> گرفتن از موتور حین بازی رقابتی آنلاین در Chess.com و Lichess تقلب است
> و حساب را می‌بندد — از این استودیو برای تمرین، مطالعهٔ وضعیت‌ها و
> تحلیل بازی‌های تمام‌شده استفاده کنید.
> جزئیات: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)

## شروع سریع

```bash
pip install -r requirements.txt

# نصب Stockfish (شدیداً توصیه می‌شود) — بدون آن، موتور جایگزین آموزشی
# داخلی اجرا می‌شود که برای نمایش فرایند خوب است ولی ضعیف است:
sudo apt install stockfish             # Ubuntu/Debian
brew install stockfish                 # macOS
# Windows: دانلود از stockfishchess.org

# ★ استودیو تحلیل زنده در مرورگر (اصلی‌ترین راه استفاده):
python -m chess_player serve --port 8000      # → http://localhost:8000

# تحلیل کامل یک بازی تمام‌شده از خط فرمان:
python -m chess_player analyze examples/opera_game.pgn --depth 14 \
    --out report.md --json report.json --html report.html

# بهترین حرکت یک وضعیت دستی (FEN):
python -m chess_player fen "rnbqkbnr/pppp1ppp/8/4p3/4P3/5N2/PPPP1PPP/RNBQKB1R b KQkq - 1 2"

# خواندن وضعیت از روی تصویر تخته و نمایش سه خط برتر موتور:
python -m chess_player image examples/sample_board.png --turn black --analyze
```

مسیر موتور را هم می‌شود صریح داد:
`--engine /usr/bin/stockfish` یا `--engine simple` برای موتور داخلی.

## استودیو تحلیل زنده چه دارد؟

| حالت | چطور کار می‌کند |
|---|---|
| 🔍 **تحلیل زنده** | برای هر دو رنگ آزادانه حرکت کنید؛ با هر تغییر، موتور دوباره تحلیل می‌کند: ارزیابی و Win٪، فلش سبز بهترین حرکت (+ خط ۲ و ۳)، جدول سه خط برتر با ادامهٔ اصلی و دکمهٔ «اجرا»، انتخاب عمق، عقب/جلو در تاریخچه، چرخش تخته، بارگذاری FEN |
| 🤖 **بازی با موتور** | شما سفیدید؛ اول حرکت می‌کنید، بعد کیفیت و دقت حرکت‌تان اعلام می‌شود و موتور پاسخ می‌دهد |
| 🎯 **حدس بهترین حرکت** | خروجی موتور پنهان است؛ شما حدس می‌زنید، بعد رتبهٔ حدس‌تان در خط‌های موتور، برچسب کیفیت و دقت را می‌بینید و آمار تمرینی‌تان جمع می‌شود؛ با چند وضعیت آمادهٔ تاکتیکی |
| 📥 **PGN** | «مرور قدم‌به‌قدم» بازی را روی تخته با تحلیل زندهٔ هر وضعیت نشان می‌دهد؛ «تحلیل کامل» گزارش دقت و اشتباه‌های هر دو بازیکن را می‌دهد |
| 🖼 **خواندن از تصویر** | فایل تصویر را می‌دهید، دو گوشهٔ تخته را روی آن کلیک می‌کنید، برنامه مهره‌ها را تشخیص می‌دهد (سیلوئت + جزئیات داخلی مهره)، در ویرایشگر اصلاح/تأیید می‌کنید و تحلیل زندهٔ همان وضعیت شروع می‌شود |

برای امتحان خواندن تصویر: فایل `examples/sample_board.png` (یک وضعیت
تاکتیکی، نوبت سیاه — پاسخ درست `g6` است) آماده است.

## رفع اشکال

### صفحه باز نمی‌شود / خطای 503 می‌گیرم

- در مرورگر **`http://localhost:8000`** را باز کنید، نه `0.0.0.0` —
  ‏`0.0.0.0` یعنی «روی همهٔ رابط‌های شبکه گوش بده» و آدرس قابل بازکردن
  نیست؛ برنامه حالا همان آدرس درست را چاپ می‌کند.
- اگر باز نشد، این‌ها را به ترتیب امتحان کنید:
  `http://127.0.0.1:8000` ‏؛ اجرای سرور روی پورت دیگر:
  `python -m chess_player serve --port 8765` و بعد
  ‏`http://localhost:8765`؛ بستن اجرای قبلی سرور (Ctrl+C در ترمینالش)
  که پورت را اشغال کرده؛ و تست سریع در ترمینال دوم:
  ‏`curl http://127.0.0.1:8000/api/health`
- اگر از پیش‌نمایش ابری (Arena) استفاده می‌کنید و 503 گرفتید، لحظه‌ای
  صبر و صفحه را تازه کنید؛ سرور بعد از هر آپدیت دوباره بالا می‌آید.

### Stockfish را دانلود کردم ولی باز SimpleEngine می‌آید

خودکار پیداش می‌کنیم، به این شرط‌ها (با دستور
`python -m chess_player doctor` دقیق می‌بینید کجاها گشتیم و هر فایل چرا
اجرا نشد):

1. فایل دانلودی را از **زیپ خارج کنید**؛ برنامه فایل اجرایی
   (‏`stockfish.exe` و مانند آن) را لازم دارد، نه خود زیپ را.
2. آن را در **ریشهٔ پروژه** یا پوشهٔ **`engines/`** بگذارید — یا مسیر
   کامل بدهید:
   ‏`python -m chess_player serve --engine "C:\مسیر\stockfish.exe"`
   یا متغیر محیطی `STOCKFISH_PATH` را روی همان مسیر بگذارید.
3. نسخهٔ مناسب سیستم‌تان باشد (معمولاً Windows x86-64؛ اگر چند نوع در
   پوشه است برنامه اول نوع‌های سازگارتر مثل AVX2 را امتحان می‌کند).
   روی لینوکس ممکن است لازم شود: ‏`chmod +x stockfish`

## ریاضیات کیفیت حرکت (خلاصه)

مدل لیچس (شرح کامل در سند معماری): امتیاز سانتی‌پیاده → Win٪ با تابع
لجستیک؛ افت Win٪ هر حرکت هم برچسب آن را تعیین می‌کند (≤۲ عالی، ≤۵ خوب،
≤۱۰ عدم دقت، ≤۲۰ اشتباه، بیش‌تر اشتباه فاحش) هم Accuracy آن را. تحلیل
زنده از MultiPV موتور استفاده می‌کند تا به جای یک حرکت، سه نامزد برتر را
با هم مقایسه کنید — برای یادگیری عمیق خیلی آموزنده‌تر از یک فلش تنهاست.

## توسعه و تست

```bash
pytest    # ۲۰ تست: موتور، تحلیل زنده و حدس حرکت، خواندن تصویر، وب‌اپ، پیداشدن Stockfish
```

ساختار:

```
chess_player/
├── engine.py            # Stockfish با UCI (MultiPV) + SimpleEngine جایگزین
├── analysis.py          # Win% ،Accuracy ،CPLoss ،طبقه‌بندی، analyze_position_multipv
├── image_fen.py         # تصویر دستی → تخته: کم‌کردن پس‌زمینه، رنگ مهره، تطابق الگو
├── piece_templates.npz  # الگوهای مهره‌ها (تولید: python -m chess_player.image_fen)
├── report.py            # گزارش Markdown / JSON / HTML + نمودار SVG
├── cli.py               # analyze / fen / image / serve
├── webapp.py            # سرور وب (کتابخانهٔ استاندارد) و APIها
└── static/index.html    # رابط کاربری استودیو تحلیل زنده
examples/                # بازی‌های نمونه + sample_board.png
docs/ARCHITECTURE.md
tests/
```
