# ♞ chess-player — مربی تحلیل شطرنج

ابزار تحلیل **کیفیت حرکت‌ها** برای ارزیابی و ارتقای سطح بازی: بازی
تمام‌شده‌تان (PGN) را به موتور Stockfish می‌دهد، هر حرکت را با بهترین
حرکت موتور مقایسه می‌کند و خروجی می‌دهد: دقت هر بازیکن (Accuracy)، میانگین
خطای سانتی‌پیاده (ACPL)، و برچسب هر حرکت (بهترین / عالی / خوب / عدم دقت /
اشتباه / اشتباه فاحش) — به‌همراه نمودار ارزیابی و نسخهٔ تمرینی تعاملی.

> ⚖️ **قانون بازی جوانمردانه**
>
> کمک گرفتن از موتور **حین** بازی آنلاین در Chess.com و Lichess تقلب است
> و حساب کاربری را می‌بندد. این ابزار عمداً فقط روی بازی‌های **تمام‌شده**،
> وضعیت‌هایی که خودتان برای مطالعه وارد می‌کنید، و بازی تمرینی **آفلاین**
> مقابل خود موتور کار می‌کند و هیچ صفحهٔ زنده‌ای را نمی‌خواند.
> توضیح کامل معماری و مرزها: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)

## شروع سریع

```bash
pip install -r requirements.txt        # فقط python-chess

# نصب Stockfish (یکی از این‌ها) — بدون آن هم برنامه با موتور جایگزین
# آموزشی داخلی اجرا می‌شود، ولی برای عددهای دقیق Stockfish واقعی بگیرید:
sudo apt install stockfish             # Ubuntu/Debian
brew install stockfish                 # macOS
# Windows: دانلود از stockfishchess.org

# ۱) تحلیل یک بازی تمام‌شده
python -m chess_player analyze examples/opera_game.pgn --depth 14 \
    --out report.md --json report.json --html report.html

# ۲) تختهٔ تحلیل: بهترین حرکت یک وضعیت (FEN)
python -m chess_player fen "rnbqkbnr/pppp1ppp/8/4p3/4P3/5N2/PPPP1PPP/RNBQKB1R b KQkq - 1 2"

# ۳) وب‌اپ تمرین آفلاین در http://localhost:8000
python -m chess_player serve --port 8000
```

مسیر موتور را هم می‌شود صریح داد:
`--engine /usr/bin/stockfish` یا `--engine simple` برای موتور داخلی.

### بازی خودم را چطور تحلیل کنم؟

1. در Chess.com: بازی → Share → **Export PGN**؛ در Lichess: بازی →
   منوی ⋮ ‏→ **Download PGN** — *بعد از پایان بازی*.
2. فایل را با دستور `analyze` بدهید (یا متنش را در وب‌اپ بچسبانید).
3. اول سراغ بخش «لحظه‌های حساس» گزارش بروید؛ برای هر اشتباه، FEN قبل از
   حرکت و خط پیشنهادی موتور هست — آن وضعیت‌ها بهترین پازل‌های تمرینی
   شخصی شما هستند.

## وب‌اپ تمرینی چه دارد؟

- **بازی مقابل موتور (آفلاین):** با سفید بازی می‌کنید؛ بعد از هر حرکت
  شما، کیفیت حرکت، دقت و انتخاب موتور اعلام می‌شود و نوار ارزیابی وضعیت
  کلی را نشان می‌دهد.
- **تحلیل PGN در مرورگر:** همان گزارش دقت/اشتباه نسخهٔ CLI.
- **تختهٔ تحلیل FEN:** بهترین حرکت و خط اصلی برای وضعیت‌های کتاب/پازل.

## ریاضیات کیفیت حرکت (خلاصه)

مدل لیچس پیاده شده است (شرح کامل در سند معماری): امتیاز سانتی‌پیاده به
Win٪ تبدیل می‌شود؛ افت Win٪ هر حرکت هم برچسب آن حرکت را تعیین می‌کند هم
Accuracy آن را. آستانه‌ها: افت ≤۲ عالی، ≤۵ خوب، ≤۱۰ عدم دقت، ≤۲۰ اشتباه،
بیش‌تر اشتباه فاحش.

```bash
pip install pytest

```

ساختار:

```
chess_player/
├── engine.py     # Stockfish (UCI) + SimpleEngine جایگزین
├── analysis.py   # Win% ،Accuracy ،CPLoss ،طبقه‌بندی حرکت‌ها
├── report.py     # گزارش Markdown / JSON / HTML + نمودار SVG
├── cli.py        # دستورات analyze / fen / serve
└── webapp.py     # وب‌اپ تمرین آفلاین (فقط کتابخانهٔ استاندارد)
examples/         # دو بازی نمونه برای امتحان
docs/ARCHITECTURE.md
tests/
```
